差分の中間状態(becoming)— form で見せる3案比較

差分を色でなく「affected 行を"変化の途中"の静的状態で、元の位置のまま描く」で見せる。 form(取消線・丸の形態・減光)が主役、色は副次。アニメ無し。 最重要: completed の途中 と deleted の途中 を form で区別できるか。 各カード: 牛乳を完了 / 会議メモを削除 / 歯医者を追加 / レポートの期日を編集(全てその場で中間状態)。

完了=元の位置に留まり点線丸+取消線(完了欄へ飛ばさない)/ 削除=becoming-gone / 追加=行頭バー+実線丸 / 編集=新値にキャレット下線
