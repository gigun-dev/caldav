⑦ チェック表現の比較 — 丸(iOS 準拠・現行) vs 四角(checkbox 風)

クリックでトグルできます(モック用の最小 JS)。

丸チェック(現行)
  • 牛乳を買う
  • 週次レポート提出(完了時: 塗り + チェック)
  • 出張の新幹線を予約
    !!7/15 (水)
四角チェックボックス案
  • 牛乳を買う
  • 週次レポート提出(完了時: チェック)
  • 出張の新幹線を予約
    !!7/15 (水)
推し: 丸チェック(現行維持)。 理由: (1) プライマリクライアント iOS リマインダーの語彙そのもの — ユーザーは 「丸 = リマインダーのタスク」を学習済みで、chat 内 UI でも同じデータが同じ見た目の言語で 現れるべき(CLAUDE.md「iOS 対応は品質基準」)。 (2) 四角い checkbox は「フォームの選択」の記号であり、「複数選択して一括操作」を 期待させてしまう(タスク完了とは意味が違う)。 (3) 丸は pending 時にそのままスピナー(上弧回転)へ変形できる — 四角では成立しない 実装上の資産が既にある。 四角が勝つのは「Web の慣習に寄せたい・ネイティブ input のフォーム送信が要る」場合だが、 本 UI はどちらにも該当しない。
